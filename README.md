# Project Management System

A role-based project management system that allows organizations to manage projects, tasks, teams, and user permissions.

## Features

- User authentication
- Role-Based Access Control (RBAC)
- Admin management
- Project creation and management
- Task creation and assignment
- Team Lead access
- Sales access
- Project Manager access
- Developer access
- Permission-based user actions

## User Roles

### Admin
- Manage users and permissions
- Full system access

### Team Lead
- Manage team tasks
- Monitor developer progress

### Sales
- View and manage client/project-related information

### Project Manager
- Create and manage projects
- Assign tasks
- Track project progress

### Developer
- View assigned tasks
- Update task status
